# Online-Pharmacy-Adoption-Analysis
ML-based analysis of online pharmacy adoption using ANN, Logistic Regression, and Decision Tree (85% accuracy)
## 📌 Overview
This project analyzes the adoption intention of online pharmacies among residents of Coimbatore using survey data.

## 🛠 Tools & Technologies
- R Programming
- Machine Learning Models:
  - Logistic Regression
  - Decision Tree
  - Artificial Neural Network (ANN)
- Sentiment Analysis
- Word Cloud Visualization

## 📊 Key Findings
- 80.6% of respondents show intention to adopt online pharmacies
- ANN achieved highest accuracy (85%)
- Key influencing factors:
  - Effort Expectancy
  - Social Influence
  - Performance Expectancy

## 📈 Models Used
- Logistic Regression (84.4%)
- Decision Tree (80%)
- Artificial Neural Network (85%)

## 💡 Insights
- Users trust online pharmacies
- Convenience and usefulness drive adoption
- Positive sentiment towards online medicine delivery

## 📂 Files Included
- Dataset (Excel)
- R Scripts
- Final Report (PDF)

## 🧾 Conclusion

The study indicates that online pharmacies are more likely to be adopted by younger individuals with higher income and education levels. Key behavioral factors such as effort expectancy, social influence, and performance expectancy play a significant role in influencing adoption.

To increase adoption rates, businesses and policymakers should focus on:
- Creating awareness through social media and digital platforms  
- Encouraging habit formation among users  
- Improving price value and service quality  

These insights provide actionable guidance for healthcare providers and policymakers to design effective strategies for promoting online pharmacy usage.
