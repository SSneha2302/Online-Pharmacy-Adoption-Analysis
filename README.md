# Online-Pharmacy-Adoption-Analysis
ML-based analysis of online pharmacy adoption using ANN, Logistic Regression, and Decision Tree (85% accuracy)
## 📌 Overview
This project analyzes the adoption intention of online pharmacies among residents of Coimbatore using survey data.

## 🛠 Tools & Technologies
- R Programming
- Machine Learning Models:
  - Logistic Regression
  - Decision Tree
  - Artificial Neural Network (ANN)
- Sentiment Analysis
- Word Cloud Visualization

## 📊 Key Findings
- 80.6% of respondents show intention to adopt online pharmacies
- ANN achieved highest accuracy (85%)
- Key influencing factors:
  - Effort Expectancy
  - Social Influence
  - Performance Expectancy

## 📈 Models Used
- Logistic Regression (84.4%)
- Decision Tree (80%)
- Artificial Neural Network (85%)

## 💡 Insights
- Users trust online pharmacies
- Convenience and usefulness drive adoption
- Positive sentiment towards online medicine delivery

- Dataset (Excel)

## 🚀 Conclusion
This project demonstrates how machine learning and sentiment analysis can be used to understand consumer adoption behavior.
